# 專名英譯規則（xinyi-water-map 英文版）

使用者 2026-09-20 拍板：**行政地名用漢語拼音，水名用台語羅馬字**。
以下把這條原則展開成可執行的分類規則。翻譯任何專名前先查這張表。

## 🔴 鐵律

**不准憑讀音自己砌英文名。** 有官方英文名的一律用官方的；查不到的照規則推導並標記，
絕不可以留一個「看起來很像」的猜測。自查一句：**這個英文名，我是查回來的還是砌回來的？**

## 分類規則

| 類別 | 規則 | 例 |
|---|---|---|
| 行政區、街道 | 官方漢語拼音 | 信義區 → Xinyi District；延吉街 → Yanji Street |
| 捷運站 | **台北捷運官方英文站名**（不可自行拼） | 六張犁站 → 待查證 |
| 學校、神學院、宮廟 | **該機構官網英文名**（不可自行拼） | 待查證 |
| 公園 | 台北市官方譯名；查不到則漢語拼音 + Park | 景勤公園 → 待查證 |
| 山 | 官方／通行名 | 象山 → Xiangshan (Elephant Mountain) |
| **清代／日治水圳、陂塘** | **台語羅馬字** + 英文類名 | 瑠公圳 → Liu-kong-tsun Canal |
| **現代排水工程（大排）** | 意譯為主 + 括號附原名 | 東大排 → East Main Drain |
| 日治時期設施 | 查證日文原名與通行英譯 | 總督府養神院 → 待查證 |

## 台語羅馬字：本專案採不帶調號的寫法

使用者既有慣例是 `Liu-kong-tsun`（見 `Liu-kong-tsun-baseline` 專案），
**不帶聲調符號**，音節間用連字號。英文版沿用同一寫法以求一致。

| 中文 | 台語羅馬字 | 完整英文名 | 依據 |
|---|---|---|---|
| 瑠公圳 | Liu-kong-tsun | Liu-kong-tsun Canal | **確立**（使用者既有專案命名，通行寫法） |
| 柴頭陂 | Tsha-thau-pi | 柴頭陂 Pond | ⚠️ **推導**，未查證 → 暫用中文原名 |
| 永春陂 | Ing-tshun-pi | 永春陂 Pond | ⚠️ **推導**，未查證 → 暫用中文原名 |
| 允龜陂 | —（讀音未確認） | 允龜陂 Pond | 查不到 |
| 舊陂溪 | —（讀音未確認） | 舊陂溪 Creek | 查不到 |
| 新埤溪 | —（讀音未確認） | 新埤溪 Creek | 查不到 |
| 神大排 | —（「神」字來歷未確認） | 神大排 Main Drain | 查不到 |

**只有「確立」那一欄可以直接用羅馬拼音。標「推導」的雖然字面讀音應該對
（柴 tshâ、頭 thâu、永 íng、春 tshun 都是標準讀法），但地名讀音未必等於
字的文讀音，沒查證就當作未確認處理。**

## 讀音未確認者的寫法（2026-09-20 使用者拍板）

查不到可靠台語讀音的水名，**保留中文原名 ＋ 英文類名**，不砌拼音：

- ✅ `允龜陂 Pond`　`舊陂溪 Creek`　`神大排 Main Drain`
- ❌ `Yun-gui Pond`（憑音硬砌，正是規則禁止的）

有可靠讀音的寫法維持：`Liu-kong-tsun Canal (瑠公圳)`。
兩種格式並存是**刻意的**——讀者一眼看得出哪些有確立的羅馬拼法、哪些還沒有。
